# OOP-CSharp

Repository lưu trữ các bài tập và bài thực hành của học phần **Lập trình hướng đối tượng**.

## Thông tin học phần

- **Tên học phần:** Lập trình hướng đối tượng
- **Mã học phần:** MI4090
- **Ngôn ngữ lập trình:** C#
- **Nền tảng:** .NET
- **Công cụ:** Visual Studio / Visual Studio Code
- **Quản lý mã nguồn:** Git / GitHub

## Nội dung học tập

Repository bao gồm các bài tập và bài thực hành được thực hiện trong quá trình học học phần **Lập trình hướng đối tượng**, tập trung vào các kiến thức cơ bản và nâng cao về lập trình hướng đối tượng trong C#, bao gồm:

- Class và Object
- Constructor
- Encapsulation (Đóng gói)
- Inheritance (Kế thừa)
- Polymorphism (Đa hình)
- Abstraction (Trừu tượng)
- Method Overloading và Method Overriding
- Interface
- Abstract Class
- Association, Aggregation và Composition
- Exception Handling
- Các bài tập tổng hợp về lập trình hướng đối tượng
